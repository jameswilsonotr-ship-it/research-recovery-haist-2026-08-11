## GitHub Release (optional, manual)

The repository itself does **not** currently hold the binary PDFs (Contents API limitation). If you want them also available as GitHub Release assets:

1. Open the repository: https://github.com/jameswilsonotr-ship-it/research-recovery-haist-2026-08-11
2. Click **Releases** (right side) → **Draft a new release**
3. Tag: `research-pdfs-v1.1.0`
4. Title: `Research PDFs v1.1.0 — Full academic corpus`
5. In the assets area, either:
   - Upload the single big file from Drive (`research_recovery_full_with_pdfs_v1.1.0_2026-08-11.tar.gz`), **or**
   - Select / drag multiple individual PDFs from the individual Drive folder
6. Publish the release

**Batch note**: The GitHub Release web UI allows selecting multiple files at once (or dragging several files into the assets box). It is not a full folder-sync, but you can attach many PDFs to one release in a single draft.
