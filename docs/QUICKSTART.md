# Quick Start

1. Read the root [README.md](../README.md).
2. Skim [system/DUAL_SSOT.md](../system/DUAL_SSOT.md) for the core design rule.
3. Open [nodes/INDEX.md](../nodes/INDEX.md) to see the 01–66 map.
4. Open [agents/INDEX.md](../agents/INDEX.md) to see which agents own which nodes.
5. For any specific node, go to `nodes/node_XX/README.md` + `PDF_MANIFEST.md`.
6. History and open work live under `history/` and `docs/TODO.md`.

This repository is documentation + structure. Binary PDFs live on Drive until manually added as Release assets or via Git LFS.
