# Dual Source of Truth (Dual SSoT)

Every research node in this system carries **two parallel anchors**:

1. **Academic** — peer-reviewed or preprint papers (OpenStax, arXiv, PMC, preprints.org). These are the archival source of truth. Prefer papers ≤ 10 years old unless the classic is foundational.
2. **Practical / Field** — handbooks, operational notes, protocol backbones, real-world logistics, or applied frameworks that make the academic material usable by agents.

PDF originals remain immutable. Markdown extracts and the folder structure in this repository are the agent-facing surface.

## Why dual

Context windows saturate. A single academic dump is not enough for an agent to act. Practical anchors give the swarm something it can actually apply (Brat Protocol lineage, air-gap interlocks, HAIST CIA/DACR/APS mechanisms, etc.).
